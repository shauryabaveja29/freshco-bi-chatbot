AI-powered Business Intelligence chatbot for CPG analytics

- **File:** `freshco_chatbot_final.html`
- **Purpose:** Working demo with FreshCo data

### Feature/Generic-Version Branch
- **File:** `generic_bi_chatbot.html`
- **Purpose:** Generic version for any dataset
- **Use:** Classmates can use with their own data

## 🚀 Quick Start (Generic Version)

### For Classmates:

1. **Get API Key** (FREE)
   - Visit: https://aistudio.google.com/app/apikey
   - Create API key

2. **Download**
   - Download `generic_bi_chatbot.html`
   - Open in browser

3. **Configure**
   - Click ⚙️ API Settings
   - Paste your API key
   - Click Save

4. **Upload Data**
   - Click 📤 Upload Excel/CSV
   - Select your file (must have headers)

5. **Ask Questions**
   - Type natural language questions
   - Get AI-powered insights

## 📊 Features

- ✅ BYOK (Bring Your Own Key) - Use your own Gemini API
- ✅ Excel/CSV Upload - Works with any dataset
- ✅ Auto-detect columns
- ✅ Natural language queries
- ✅ No backend needed - runs in browser

## 🔐 Privacy

- API key stored locally in your browser
- Data processed in-browser
- Nothing sent to external servers except Gemini API
